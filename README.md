This is a typical game of imposters.
A host can choose how many imposters and if the imposter gets fake word. If a fake word is given, all imposters will get the same fake word.
Players can join the game buy entering a link or by entering code of the room.
Host and Players can reveal their secret word by pressing 'Hold to REveal' button.
The Host can click on 'Back to Lobby' when game is over and the imposters are shown in a pop up message. Allo Players are taken back to the Lobby.
The imposter can once again play the game by clicking on 'Start Game'. This will issue a fresh secret word to Players.
In the Lobby, the Host can 'Remove' Players or 'Close Room'
